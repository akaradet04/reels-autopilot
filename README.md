# Reels Autopilot

ระบบผลิตและโพสต์ Facebook Reels อัตโนมัติหลายเพจ ตั้งค่าผ่านเว็บ แจ้งเตือนผ่าน Telegram

```
web/        เว็บที่คุณใช้ (Next.js บน Vercel)
worker/     เครื่องผลิตคลิป (Python + FFmpeg) ตื่นทุก 30 นาทีบน GitHub Actions
supabase/   ฐานข้อมูล ตารางและสิทธิ์การเข้าถึง
```

## ติดตั้งครั้งแรก (ประมาณ 45 นาที)

ทำตามลำดับ เพราะแต่ละขั้นใช้ค่าจากขั้นก่อนหน้า

### 1. Supabase (ฐานข้อมูล ฟรี)
1. สมัครที่ supabase.com → New project → Region เลือก **Southeast Asia (Singapore)**
2. เมนู **SQL Editor** → วางเนื้อหาไฟล์ `supabase/migrations/0001_init.sql` ทั้งหมด → Run
3. เมนู **Authentication → Users → Add user → Create new user** ใส่อีเมลและรหัสผ่านของคุณ ติ๊ก *Auto Confirm User*
   คนแรกที่สร้างจะเป็น **เจ้าของ** ระบบโดยอัตโนมัติ
4. เมนู **Project Settings → API** จดค่า `Project URL`, `anon public` key และ `service_role` key (ห้ามเปิดเผย)

### 2. ENCRYPTION_KEY
ตัวอักษรสุ่มยาว 32 ตัวขึ้นไป ใช้เข้ารหัสกุญแจทุกอย่างที่ใส่ผ่านหน้าเว็บ **ห้ามเปลี่ยนภายหลัง** ไม่งั้นต้องใส่กุญแจทุกอย่างใหม่

### 3. Vercel (เว็บ)
1. vercel.com → Add New Project → เลือก repo นี้ → **Root Directory = `web`**
   (หรือ deploy จากเครื่องด้วย `npx vercel deploy --prod` ในโฟลเดอร์ `web`)
2. ใส่ Environment Variables 4 ตัวตามไฟล์ `.env.example` → Deploy

### 4. GitHub (เครื่องผลิตคลิป)
1. สร้าง repository แบบ **Public** แล้วอัปโหลดโฟลเดอร์นี้ทั้งหมด
2. **Settings → Secrets and variables → Actions → New repository secret** ใส่
   `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `ENCRYPTION_KEY`
3. แท็บ **Actions** → เปิดใช้ workflow ชื่อ `worker`

### 5. ตั้งค่าในเว็บ (ทุกอย่างทำจากหน้าตั้งค่า มีคำแนะนำบนจอ)
1. เข้าสู่ระบบด้วยอีเมลจากขั้น 1.3
2. **ตั้งค่า → Telegram → ตั้งค่า Telegram** สร้างบอทกับ @BotFather วาง token แล้วเชื่อมแชท
3. **ตั้งค่า → Facebook App** สร้างแอปที่ developers.facebook.com แล้วใส่ App ID / App Secret
   แอปแบบ **Development mode** ทดสอบแล้ว (19 พ.ย. 2569): โพสต์ Reel ลงเพจที่คุณเป็นแอดมินได้ และ**คนทั่วไปที่ไม่ได้ล็อกอินเห็นโพสต์** ไม่ต้องส่งให้ Facebook ตรวจ
   (เอกสาร Meta ระบุว่าข้อมูลที่แอปสร้างในโหมดนี้เห็นได้เฉพาะคนมีบทบาทในแอป ผลจริงต่างออกไปสำหรับโพสต์ในนามเพจ ถ้าวันหนึ่งคนทั่วไปมองไม่เห็น ให้เปลี่ยนแอปเป็น Live)
   ถ้าจะให้คนอื่นเป็น **แอดมินสำรอง** ให้เพิ่มเขาที่ **App roles → Roles** ด้วย
4. **ตั้งค่า → คีย์ของบริการ** ใส่ Gemini API key และ Pexels API key (ฟรีทั้งคู่)
5. **เพจ → + เพิ่มเพจ → เชื่อมต่อด้วย Facebook** เลือกเพจ
6. แตะแต่ละเพจ เลือกหมวด จำนวนคลิปต่อวัน ช่วงเวลา สไตล์ แล้วเปิดใช้งาน
7. **สไตล์** อัปโหลดโลโก้ตะเกียงใจ ปรับสีและเสียง
8. ทดสอบ: **คิวคลิป → + สร้างเอง** พิมพ์หัวข้อ เลือกเพจ 1 เพจ แล้วรอ Telegram เด้ง

จากนั้นระบบวางแผนเองทุกคืน 00:30 และโพสต์ตามเวลา

## เปิดเว็บบนเครื่อง (localhost:4600)

ดับเบิลคลิก `Reels Autopilot.lnk` ในโฟลเดอร์นี้ (ลากไปไว้บนเดสก์ท็อปได้)
ถ้าเว็บยังไม่ทำงาน จะเปิดเบื้องหลังให้ แล้วเปิดเบราว์เซอร์ที่ http://localhost:4600
ปิดเว็บ: คลิกขวา `stop-web.ps1` → Run with PowerShell · log อยู่ที่ `logs\web.log`
หลังแก้โค้ดในโฟลเดอร์ `web` ให้ปิดเว็บ แล้วรัน `npm --prefix web run build` ก่อนเปิดใหม่

## เรื่องที่ควรรู้

- **เสียงพากย์** ใช้ **Gemini** เป็นหลัก (ฟรี ใช้คีย์เดียวกับเขียนบท) ถ้าไม่ว่างหรือโควตาหมด ระบบพากย์ทั้งคลิปใหม่ด้วย
  Edge TTS แล้ว Azure Speech ตามลำดับ (ไม่สลับเสียงกลางคลิป) Edge TTS ไม่ใช่บริการทางการของ Microsoft ทดสอบแล้วตอบกลับครึ่งเดียว
  โควตาฟรีของเสียง Gemini จำกัด **3 ครั้งต่อนาทีต่อโมเดล** (Google ระบุใน error 429) ระบบเว้นจังหวะเรียกให้เอง
  คลิปหนึ่งใช้เวลาพากย์ราว 2 นาที ไม่ติด 429 ส่วนโควตารายวัน Google ไม่ได้ประกาศ ทดสอบเรียกเกิน 50 ครั้งแล้วยังไม่ติด
  ถ้าจะผลิตวันละหลายสิบคลิปและวันหนึ่งโควตารายวันเต็ม ระบบสลับไป Azure Speech (ถ้าใส่คีย์ ฟรี 500,000 ตัวอักษร/เดือน แต่ต้องใช้บัตรสมัคร) แล้ว Edge
- **GitHub Actions** ข้อตกลงการใช้งานของ GitHub ระบุให้ใช้ Actions กับงานของซอฟต์แวร์ใน repo นั้น
  การใช้รันงานผลิตคอนเทนต์ทุกวันมีความเสี่ยงถูกจำกัดการใช้งาน ถ้าเกิดขึ้น ย้าย worker ไปรันที่เครื่องอื่นได้ทันที (ดูด้านล่าง)
- GitHub จะ **หยุด schedule อัตโนมัติ** ถ้า repo ไม่มีการเปลี่ยนแปลง 60 วัน และส่งอีเมลเตือนก่อน กดเปิดใหม่ในแท็บ Actions ได้
- Supabase แพ็กเกจฟรีจะพักโปรเจกต์ที่ไม่มีการใช้งาน 7 วัน worker เรียกใช้ทุก 30 นาทีจึงไม่โดนพัก
- ไฟล์วิดีโอที่โพสต์แล้วเกิน 3 วันจะถูกลบจาก storage อัตโนมัติ เพื่อไม่ให้เกิน 1GB

## รัน worker ที่เครื่องอื่น

worker เป็นคำสั่งเดียว ต้องมี Python 3.11+ และ FFmpeg

```bash
pip install -r worker/requirements.txt
```

```bash
python -m worker tick
```

ตั้ง cron ให้รันทุก 30 นาที พร้อม environment variables 3 ตัวเหมือนใน GitHub

ดูหน้าตาคลิปโดยไม่ต่อฐานข้อมูล:

```bash
python -m worker sample out.mp4 background.mp4
```

## ทดสอบ

```bash
python -m worker.tests.test_core
```
